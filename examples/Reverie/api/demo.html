🌳 拓扑切分演示系统

通信树拓扑智能切分工具

📖 使用说明

快速开始

1. 确保拓扑切分API服务已启动: python start_tree_cut_api.py

2. 默认API地址: http://localhost:8001

3. 点击下方"拓扑切分"按钮开始切分

4. 切分完成后将弹出窗口展示结果文件

⚠️ 请确保API服务正常运行，否则切分操作将失败

💻 代码示例

💡 以下是在Vue项目中使用该组件的示例代码 
<template>
  <div>
    <!-- 基础用法 -->
    <tree-cut-button />

    <!-- 完整配置 -->
    <tree-cut-button
      api-url="http://localhost:8001"
      output-dir="MyTreeGroup"
      :tree-data="myTreeData"
      @cut-complete="handleComplete"
      @cut-error="handleError"
    />
  </div>
</template>

<script>
import TreeCutButton from './TreeCutButton.vue'

export default {
  components: {
    TreeCutButton
  },
  data() {
    return {
      myTreeData: {
        nodes: [...],
        edges: [...]
      }
    }
  },
  methods: {
    handleComplete(result) {
      console.log('切分完成:', result)
    },
    handleError(error) {
      console.error('切分失败:', error)
    }
  }
}
</script>

📝 组件参数

Props (属性)

apiUrl - API服务地址，默认: http://localhost:8001

treeData - 树数据对象，默认使用示例数据

outputDir - 输出目录名称，默认: TreeGroup

Events (事件)

@cut-complete - 切分完成时触发，返回结果对象

@cut-error - 切分失败时触发，返回错误信息
