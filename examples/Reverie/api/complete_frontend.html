功能详情介绍

本平台旨在构建智算网络数字孪生平台，加速智算网络仿真，实现端侧、网内通信行为高精度刻画，为智算网络的拓扑、协议以及拥塞控制算法设计提供方案

图驱动的集合通信流量

基于DAG构建算子级大模型训练流量，驱动智算网络仿真引擎。

混合粒度仿真

自动切换仿真粒度，同时满足仿真精度和速度的需求。

时空切分并行仿真

基于大模型训练流量的时空特性，实现仿真多进程加速。
