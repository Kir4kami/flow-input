## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动 API 服务

```bash
python3 start_tree_cut_api.py
```

服务将运行在 `http://localhost:8001` 或 `http://localhost:8002`

### 3. 使用演示页面

#### 方式 A：使用 HTTP 服务器（推荐）

```bash
# 启动 HTTP 服务器
python3 -m http.server 8888

# 在浏览器中访问
# http://localhost:8888/demo.html
# http://localhost:8888/test_new.html
```

#### 方式 B：一键启动

```bash
./start_demo.sh
```

## 🔧 API 接口

### 主要端点

```
GET  /health              # 健康检查
GET  /example-tree        # 获取示例数据
POST /tree-cut            # 执行拓扑切分
```

### 使用示例

```bash
# 健康检查
curl http://localhost:8002/health

# 执行切分
curl -X POST http://localhost:8002/tree-cut \
  -H "Content-Type: application/json" \
  -d @test/sample_tree_data.json
```

## 💻 在 Vue 项目中使用

```vue
<template>
  <tree-cut-button 
    api-url="http://localhost:8002"
    @cut-complete="handleComplete"
  />
</template>

<script>
import TreeCutButton from './TreeCutButton.vue'

export default {
  components: { TreeCutButton },
  methods: {
    handleComplete(result) {
      console.log('切分完成:', result)
    }
  }
}
</script>
```

## ❓ 常见问题

### Q: Chrome 显示 "Failed to fetch"？

A: 使用 HTTP 服务器托管页面：
```bash
python3 -m http.server 8888
# 然后访问 http://localhost:8888/demo.html
```

### Q: 端口被占用？

A: API 会自动切换到下一个可用端口（8001 → 8002）

### Q: 如何停止服务？

A: 
```bash
# 查找进程
ps aux | grep tree_cut_api

# 停止进程
kill <PID>
```
