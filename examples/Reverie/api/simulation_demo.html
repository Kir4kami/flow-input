网络仿真系统演示

完整的网络拓扑、负载、切分、仿真一体化控制系统

使用说明

快速开始

1. 确保API服务已启动: python3 start_complete_api.py

2. 默认API地址: http://localhost:8000

3. 按顺序执行：拓扑设置 → 负载配置 → 拓扑切分 → 启动仿真

4. 使用稳态监控观察仿真状态，完成后查看分析结果

⚠️ 请确保API服务正常运行，否则操作将失败

API调用示例

💡 以下是使用JavaScript调用API的示例代码 
// 1. 生成拓扑
const topologyResponse = await fetch('http://localhost:8000/generate-topology', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    torSwitches: 8,
    spineSwitches: 4
  })
});

// 2. 生成负载
const loadResponse = await fetch('http://localhost:8000/generate-load', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    host_num: 64,
    msg_len: '32*(1024)',
    dp: 8
  })
});

// 3. 执行切分
const cutResponse = await fetch('http://localhost:8000/tree-cut', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    output_dir: 'TreeGroup'
  })
});

// 4. 启动仿真
const simResponse = await fetch('http://localhost:8000/run-simulation', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    task_num: 4,
    enable_mixed_granularity: true,
    llm_model: 'deepseek',
    simulation_time: 10.0
  })
});

API接口列表

拓扑管理

POST /generate-topology - 生成网络拓扑

POST /visualize-topology - 可视化拓扑结构

GET /get-topology-image - 获取拓扑图像

负载配置

POST /generate-load - 生成负载配置

POST /modify-load-file - 修改负载文件

拓扑切分

POST /tree-cut - 执行拓扑切分

GET /example-tree - 获取示例树数据

仿真控制

POST /run-simulation - 启动仿真

POST /stop-simulation - 停止仿真

GET /simulation-status - 查询仿真状态

稳态监控

POST /start-steady-state-monitor - 启动稳态监控

POST /stop-steady-state-monitor - 停止稳态监控

GET /steady-state-monitor - 获取稳态状态

结果分析

POST /analyze-results - 分析仿真结果

GET /read-file - 读取文件内容

GET /list-files - 列出目录文件
